# Johto Life

Ambient NPCs and Common Courtesy for **Pokémon Gold / Silver / Crystal** on [gen1recomp](https://github.com/bryanthaboi/gen1recomp).

**Separate from [Kanto Life](https://github.com/jtfresh90/Kanto-Life-Mod)** (Red/Blue/Yellow).

**Repo:** https://github.com/jtfresh90/Johto-Life-Mod

## Install

1. Download from this repo:
   - [main.lua](https://raw.githubusercontent.com/jtfresh90/Johto-Life-Mod/main/main.lua)
   - [manifest.json](https://raw.githubusercontent.com/jtfresh90/Johto-Life-Mod/main/manifest.json)
2. Zip them together with both files at the **root** of the zip (not in a subfolder).
3. Import the zip in gen1recomp.
4. Enable **Johto Life** only (disable Kanto Life on Gold).

Compatible with gen1recomp **0.2.x**.

## Features

- Extra outdoor/indoor NPCs (Johto towns + routes)
- Random Gen 2 sprites with gendered English names
- Common Courtesy (knock / walk-in eject)
- **JOHTO LIFE** under Options
- Sleep toggles for ambient NPCs

## Options

| Option | Notes |
|--------|--------|
| EXTRA NPCS | Master toggle |
| EXTRA NPC COUNT | 0–150; once changed, **0 means no extras** |
| INDOOR NPCS / COUNT | Buildings |
| COMMON COURTESY | Knock before entering houses |
| SLEEPING NPCS / RATE / DAY SLEEPERS | Ambient sleep behavior |
